# Komentář k zákonu č. 22/1997 Sb., o technických požadavcích na výrobky a o změně a doplnění některých zákonů

Otevřený komentář k zákonu o technických požadavcích na výrobky — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; technické předpisy a české technické normy, harmonizované a určené normy, poplatky a sponzorovaný přístup, státní zkušebnictví, autorizace a autorizované osoby, posuzování shody, akreditace, dozor, ochranná opatření, přestupky a změny souvisejících zákonů.

Konsolidované znění: dokument e-Sbírky `SB-1997-00022_2025-10-01`.
